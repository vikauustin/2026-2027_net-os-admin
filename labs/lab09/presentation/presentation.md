# Вводная часть

## Цель работы

Приобретение практических навыков по установке и простейшему конфигурированию POP3/IMAP-сервера.

## Задание

1. Установить на виртуальной машине server Dovecot и Telnet для дальнейшей проверки корректности работы почтового сервера.
2. Настроить Dovecot.
3. Установить на виртуальной машине client программу для чтения почты Evolution и настроить её для работы с почтой своего пользователя. Проверить корректность работы почтового сервера как с виртуальной машины server, так и с виртуальной машины client.
4. Изменить скрипт для Vagrant, фиксирующий действия по установке и настройке Postfix и Dovecot на виртуальной машине server, создать скрипт для Vagrant, фиксирующий установку Evolution на виртуальной машине client, и внести соответствующие изменения в Vagrantfile.

В `/etc/dovecot/dovecot.conf` добавлена строка `protocols = imap pop3`. В `10-auth.conf` проверен метод аутентификации `auth_mechanisms = plain`, в `auth-system.conf.ext` для проверки паролей используется драйвер pam.

# Заключение

## Выводы

В ходе работы получены практические навыки по установке и простейшему конфигурированию POP3/IMAP-сервера Dovecot. Dovecot настроен на работу по протоколам IMAP и POP3 с хранением почты в формате Maildir, а Postfix настроен на доставку писем в тот же каталог. С клиента через Evolution отправлены письма и получен доступ к ящику по IMAP, на сервере работа проверена командами mail, doveadm, анализом журнала и подключением по POP3 через telnet. Действия по настройке зафиксированы в скриптах `mail.sh` для сервера и клиента.
